# CardCraftMini

A digital business card created with HTML and CSS.

## Features
- Centered business card
- Profile photo and biography
- Contact button
- Email, LinkedIn, and Instagram links
- Poppins font
- Custom colors and rounded borders
- Hover effects
- Flexible sizing for small screens

## Color palette
- Page: #F4F1EA
- Card: #FFFFFF
- Accent: #3D5A80
- Text: #293241

## Technologies
- HTML5
- CSS3
- Google Fonts
